# DungeonEscape
2D Dungeon Escape for fun!

## How to Play

1. Click **Play** on the title screen.
2. Use **WASD** or the **arrow keys** to move.
3. Collect the yellow key.
4. Avoid the orc. Contact with the enemy reduces your health.
5. Reach the exit with the key to win.
6. Click **Restart** after winning or losing to play again.

## Features

- Animated player and enemy sprites
- An orc that chases the player
- Three health points with a short damage cooldown
- A collectible key and a locked exit
- Dungeon walls, furniture, and animated torches
- Health and key status displays
- Title, victory, and game-over screens

## Built With

- Unity 6.3 LTS (6000.3.25f1)
- C#
- Unity Input System
- TextMeshPro
- Unity 2D physics and animation tools

## Open the Project

1. Clone or download this repository.
2. Add the project folder through Unity Hub.
3. Open it with Unity 6.3 LTS.
4. Open `Assets/Scenes/DungeonLevel.unity`.
5. Press Play in the Unity Editor.
6. Click **Play** on the game's title screen.
